# Team Task Manager

A full-stack Team Task Manager application built using Node.js, Express.js, MongoDB, JWT Authentication, and Railway deployment.

---

## Features

- User Signup & Login
- JWT Authentication
- Role Based Access Control
- Project Creation
- Task Creation
- Task Assignment
- Task Status Tracking
- Dashboard APIs
- MongoDB Database
- Railway Deployment

---

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Railway
- Postman

---

## API Endpoints

### Auth APIs
- POST /api/auth/signup
- POST /api/auth/login

### Project APIs
- POST /api/projects/create
- GET /api/projects

### Task APIs
- POST /api/tasks/create
- GET /api/tasks
- GET /api/tasks/:id
- PUT /api/tasks/update/:id
- DELETE /api/tasks/delete/:id
